# 🎰 Java Casino Game Simulation

An interactive console-based Casino simulation application built using Java. This project demonstrates core Object-Oriented Programming (OOP) concepts, clean decision-making architecture, and state management in a Java environment.

## 🚀 Key Features
- **Player Balance Management:** Handles chips/cash balances, deposits, and bet validations.
- **Game Logic Implementation:** Interactive text-based gameplay featuring classic casino mechanics.
- **Modular OOP Architecture:** Clean separation of concerns with encapsulated domain classes and control structures.

## 🛠️ Tech Stack & Concepts
- **Language:** Java
- **Core Concepts:** Object-Oriented Programming (OOP), Encapsulation, Polymorphism, Abstraction, Control Flow, and Exception Handling.
- **Development Tools:** NetBeans IDE, Git, GitHub.

## 💻 How to Run

1. **Clone the repository:**
   git clone https://github.com/tu-usuario/java-casino-simulator.git

2. **Navigate to the source directory:**
   cd java-casino-simulator/src

3. **Compile and run via command line:**
   javac Main.java
   java Main
